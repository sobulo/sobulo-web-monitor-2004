# Original transcription

This directory contains a faithful transcription of source code as printed in the thesis appendix. "Original" identifies the archival transcription layer; it does not mean that a surviving electronic 2004 source file was recovered.

Machine-extracted PDF text is not original source code and is not stored here. Extraction output belongs under the separate `work/` directory and is used only as an aid during visual verification.

The transcription preserves routine names, comments, spelling, structure, and apparent defects. Only documented, unambiguous typesetting repairs and removal of printed line numbers are permitted.
