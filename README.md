# sobulo-web-monitor-2004

Historical software archive for the Perl monitoring-system backend printed in Appendix A of Olusegun Sobulo's 2004 University of Illinois at Urbana-Champaign master's thesis, *Query Translation for an Information Integration System and Building a Monitoring System*.

## Stage 1 scope

This stage preserves source provenance and begins a human-verifiable transcription of the printed appendix. It does not restore, refactor, modernize, correct, compile, test, or extract modules from the implementation.

The current transcription batch covers logical thesis pages 38-42 (physical PDF pages 45-49), printed lines 1-243.

## Repository areas

- `source/` contains the published thesis PDF and its source-artifact documentation.
- `original/appendix-a/` contains the faithful transcription and its audit records.
- `docs/` records provenance, method, corrections, visible functions and dependencies, and AI assistance.
- `work/` contains derived page renders and machine-extracted working text for public verification.

Machine-extracted text is working evidence only. It is not represented as original source code.

The committed thesis PDF is the primary published reference. The `source/`, `original/`, and `work/` boundaries deliberately distinguish the source publication, the archival code transcription, and derived verification artifacts.
