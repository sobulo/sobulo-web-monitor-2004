# Derived verification artifacts

Everything under `work/` is derived from the committed thesis PDF in `source/` and is retained to make the transcription publicly auditable.

These files are **not original source code**:

- `appendix-a/appendix-a.txt` is a normal machine text extraction of Appendix A.
- `appendix-a/appendix-a-layout.txt` is a layout-preserving machine text extraction.
- `appendix-a/pages/` contains 300-DPI PNG renders of every Appendix A page. Each filename uses the physical PDF page number; physical pages 45-69 correspond to logical thesis pages 38-62.

The human-verifiable Perl transcription is separate at `original/appendix-a/MonitorUtils.thesis.pl`. The published source document is separate at `source/SobuloMasterThesis.pdf`.
