# Provenance

## Source chain

The transcription source is the local file `source/SobuloMasterThesis.pdf`, copied with the owner's authorization from the Google Drive folder named `old 2004 thesis`. The Drive file was named `SobuloMasterThesis.pdf`, had MIME type `application/pdf`, and had a reported size of 995,756 bytes. The local copy has the same size and SHA-256 `5a93da938c6b363d4484bd482308a7a03305f540b98c3e27066cd7fe28ef97ea`.

The PDF identifies itself as TeX output created in 2004 and contains 72 physical pages. It is committed so the public can compare the transcription directly with its published source.

## Appendix boundary

The appendix was identified by the visible heading "Appendix A" followed by "Perl Code for Monitoring System" on physical PDF page 45, which bears logical thesis page number 38. The next major section, "References," begins on physical PDF page 70 and logical thesis page 63. Appendix A therefore spans logical pages 38-62 and physical PDF pages 45-69.

## Archival layers

- `source/`: the published thesis PDF and its source-artifact description.
- `work/`: derived machine renderings and text extractions used for comparison.
- `original/appendix-a/`: human-verifiable transcription and its manifest/notes.
- `docs/`: provenance and process documentation.

No claim is made that PDF text extraction recovers an electronic original. The `.thesis.pl` file is a transcription of printed code.
